Blender 建模篇 2.1：点线面的选择与控制

课程：【Kurt】Blender 零基础入门教程（UP 主：KurTips）
章节：建模篇 2.1 · P6 · 时长约 13 分半
记录时间：2026-11-09

一句话总结：这节课只干两件事——把点、线、面选准，再把它们动对，最后补上”法线”这一课，因为面的正反会直接影响后面的材质、渲染，甚至游戏引擎里的显示。

一、先分清”模式”

Blender 里同一个物体有多个”工作层”，最常用的是两个：

模式 你在操作什么 进入方式
物体模式 Object Mode 把物体当成一个整体：移动、旋转、缩放、复制 默认模式
编辑模式 Edit Mode 钻进物体内部，编辑它的点、线、面 选中物体后按 Tab
  • Tab：在物体模式和编辑模式之间来回切换，最常用的一个键。
  • Ctrl + Tab：呼出”模式饼菜单”，一次性看到所有模式（雕刻、顶点绘制、权重绘制、UV 编辑……）。
  • 更顺手的方式：到 编辑 → 偏好设置 → 界面，勾选”拖动激活饼菜单“（Pie Menu on Drag）。之后按住 Tab 不松手并拖动鼠标，就能像游戏里切武器一样甩出模式轮盘，松开选中即可。

小提示：视频里演示的”甩鼠标切模式”就是靠这个偏好设置，默认是关的，不勾选的话长按 Tab 不会有轮盘。

二、点、线、面：建模的三个层级

元素 英文 它是什么 选择模式快捷键
顶点 Vertex 空间中的一个点，没有大小 1
边 Edge 两个顶点之间的连线 2
面 Face 至少三条边围成的多边形（Blender 允许 n-gon） 3

几个容易踩的点：

  • 1 / 2 / 3 用的是主键盘区的数字，不是右侧小键盘。笔记本如果开了”模拟数字键盘”，按 1 会变成切换视图，需要去偏好设置里关掉或改键。
  • 按住 Shift 再点顶部那三个模式按钮，可以同时开启多种选择模式（比如点 + 边一起选）。
  • 切换选择模式时，已选内容会按拓扑关系”换算”保留：点全选了，切到边模式会选中由这些点组成的边。这点在建模时很好用。

三、选择：把该选的选出来

1. 基础选择

  • 左键单击：选中；Shift + 单击：加选 / 取消单个元素。
  • A：全选；Alt + A：取消全选；Ctrl + I：反选。
  • 点击空白处：取消当前选择。
  • 框选时按住 Shift 是加选、按住 Ctrl 是减选。

2. 三种选择工具

工具 快捷键 用法
框选 Box B 拉一个矩形框，框内元素被选中
刷选 Circle C 变成圆形笔刷，按住左键涂抹选择；滚轮调笔刷大小；中键（部分版本 Ctrl + 左键）擦除；Esc / 右键退出
套索 Lasso Ctrl + 右键拖动 手绘一个闭合区域，圈中的被选中

按 W 可以在几种选择工具之间循环切换。如果按 W 没反应，先确认鼠标没有停在左侧工具栏上、输入法是不是英文。

3. 智能选择（本节重点）

想做的事 操作 说明
选一整圈 Alt + 单击 循环选择：点边选一圈边，点面选一圈面；点靠近纵向的边和横向的边，选出的方向不同
选平行的环 Ctrl + Alt + 单击（部分版本是双击） 环形选择：一次选中同一”纬度”上所有平行边，做花瓶、圆柱、管道类模型非常常用
两点之间连一条路径 Ctrl + 单击（新版可能为 Ctrl + 右键，以左下角提示为准） 最短路径选择，跨面连接两点
选中相连的一整块 L 鼠标要悬停在物体上再按，选中与它连通的所有点线面
同上，但不想移动鼠标 Ctrl + L 选中当前已选元素所在的整块，鼠标在哪都行
扩大 / 缩小选区 Ctrl + 小键盘 + / Ctrl + 小键盘 - 必须是小键盘的加号、减号
随机选一部分 选择菜单 → 随机选择 可调比例，用来做自然感、破损感、随机错位

视频里的例子：L 选不中整个猴头，不是因为有三角面，而是因为眼睛和头部本来就不是连通的网格。角色建模时眼球常和眼眶分开做，方便后面单独做动画，所以 L 只会选中眼睛这一块。

4. 透视选择：Alt + Z

实体模式下的框选只能选到正对你的那一面，背面的点线面选不到。按 Alt + Z 打开透视模式（X-Ray），模型变半透明，框选就能穿透到背面。

  • 再按一次 Alt + Z 退出。
  • 这个键经常和 N 卡 / AMD 驱动的录屏、游戏内浮窗快捷键冲突，按下去弹出显卡面板的话，去驱动设置里把那个热键改掉即可。
  • 也可以按 Z 调出着色方式菜单，在里面切换透视 / 实体。

四、控制：选中之后怎么动

操作 快捷键 技巧
移动 G 按下后只动鼠标，不要再点任何键；点左键确认，点右键 / Esc 取消
旋转 R 围绕选中元素的中点旋转
缩放 S 围绕选中元素的中点缩放
锁定单轴 G / R / S 后按 X、Y、Z 只在指定轴上动
在平面内动 Shift + X/Y/Z 排除该轴，比如 Shift + Z 就是在 XY 平面上移动
精确数值 变换中直接输入数字再回车 例如 G X 2 Enter = 沿 X 轴精确移动 2 米
吸附 变换中按住 Ctrl 按固定步长吸附，适合对齐网格
撤销 Ctrl + Z 建模时按得最多的键之一

**关于”点模式下不能缩放、旋转”**：单个顶点没有尺寸也没有方向，S 和 R 又是围绕”选中元素的中点”进行的，所以对一个孤立顶点做缩放或旋转，画面看起来毫无变化。这不是功能坏了——多选几个点，或者切到边 / 面模式，再按 S / R 就能看到效果。视频里说的”点模式无法缩放旋转”，指的就是这个现象。

变换的轴心默认是”选中元素的中点”（Median Point），所以选的位置不同，缩放和旋转的结果也不同。这是新手最常见”怎么越转越歪”的原因，后面讲轴心点时还会展开。

五、删除：X 和 Ctrl + X 不是一回事

按 X 会弹出一个删除菜单，选什么删什么：

选项 效果
顶点 Vertices 删点，连带与它相连的边和面一起消失
边 Edges 删边，面上出现破洞
面 Faces 删面，只留下边界线
仅边和面 Only Edges & Faces 保留顶点，删掉边和面
仅面 Only Faces 只删面，边和点都保留

而 Ctrl + X 是”融并“（Dissolve）：删掉元素的同时把周围的网格缝合起来，不留洞。比如 Ctrl + X 融并一条边，两侧的面会合并成一个面。

建模习惯：动手前先想清楚——我是要”挖掉一块”（X），还是要”把这条线抹平”（Ctrl + X）？视频里特意强调过，删来删去很容易把自己删蒙。

六、法线：面的正反，决定光的去向

法线是垂直于面（或顶点）的单位向量，它决定了光线从哪个方向照过来、面朝哪边”算正面”。做模型时如果法线反了，材质会发黑、渲染会漏光，导入游戏引擎后甚至整块面直接消失。

1. 面朝向（Face Orientation）

打开后可以直观看到面的正反：

  • 蓝色 = 正面，红色 = 反面（视频录制时是 3.x 的配色）。
  • 新版 Blender 里正面可能显示为灰 / 白，只把反面标红。如果看不到蓝色，去 偏好设置 → 主题 → 3D 视图 → 面朝向，把正面颜色的 Alpha 调高即可。
  • 显示开关的位置随版本变化：4.x 在右上角的”网格编辑模式“叠加层里，旧版在视图叠加层下拉菜单里。

2. 三种法线显示

在叠加层里可以分别打开：

  • 顶点法线：每个顶点上垂直伸出的线。
  • 面法线：每个面中心垂直伸出的线。
  • 拆分法线（Split Normals）：在法线被”拆开”的地方显示分裂的线，用于检查硬边和自定义法线。

3. 重算法线

操作 快捷键 说明
重新计算外侧 Shift + N 最常用，把法线统一翻到外面
重新计算内侧 Ctrl + Shift + N 翻转到里面，做内壁、房间内部时用
打开法向面板 Alt + N（4.x） 里面有翻转、重算、设置自定义法线等选项

从外部导入模型、做完镜像或对称、或者用布尔运算之后，第一件事就是开面朝向看一眼，有红色就 Shift + N。

七、快捷键速查

选择

快捷键 作用
Tab 物体模式 / 编辑模式 切换
Ctrl + Tab 模式饼菜单
1 / 2 / 3 点 / 边 / 面 选择模式
A / Alt + A / Ctrl + I 全选 / 取消全选 / 反选
B / C / Ctrl + 右键拖动 框选 / 刷选 / 套索
Alt + 单击 循环选择（一圈）
Ctrl + Alt + 单击 环形选择（平行的一圈）
Ctrl + 单击 最短路径
L / Ctrl + L 选择相连元素（悬停 / 不悬停）
Ctrl + 小键盘 + / - 扩大 / 缩小选区
Alt + Z 透视模式（穿透框选）

控制

快捷键 作用
G / R / S 移动 / 旋转 / 缩放
X / Y / Z 锁定单轴
Shift + X/Y/Z 排除该轴（在另外两轴的平面内）

八、踩坑清单

  1. 快捷键没反应：九成是输入法还在中文，切到英文；或者鼠标正停在左侧工具栏上。
  2. 按 1 / 2 / 3 变成切视图：笔记本开了”模拟数字键盘”，去偏好设置关掉，或改用鼠标点顶部的模式按钮。
  3. Ctrl + 小键盘 + 没反应：那个加减号必须是数字小键盘上的，主键盘区的不行。
  4. Alt + Z 弹出显卡驱动面板：N 卡 / A 卡的热键冲突，去驱动里改掉，或改用 Z 菜单。
  5. 打开面朝向看不到蓝色：新版本正面默认灰 / 白，去主题里把 Alpha 调高；或者你的模型是封闭立体，只有内部才是红的。
  6. L 选不中想要的部分：鼠标必须悬停在物体上；如果两部分的网格本来就没连通，L 只会选中其中一块。
  7. 版本差异：视频录于 2023 年（3.x），现在 4.x / 5.x 的菜单位置和部分快捷键都变了。拿不准时看左下角状态栏的提示，它永远比教程准。

九、跟着视频练一遍

  1. 用默认的猴头 Suzanne：Alt + 单击 选一圈边，Ctrl + Alt + 单击 选平行边环，L 选整块，Ctrl + 单击 连两点，感受这四种选择的差别。
  2. 新建一个圆柱，Ctrl + Alt + 单击 选中中间一圈边，S 缩放，再隔几圈缩放一次，做出花瓶的轮廓。
  3. 不开 Alt + Z 框选一次背面，再开 Alt + Z 框选一次，对比结果。
  4. 按 Shift + N 和 Ctrl + Shift + N 来回翻转，打开面朝向观察红蓝变化。
  5. 用”随机选择”选一部分面，G 轻轻推一下，体会随机带来的自然感。

十、复盘三句话

  1. 建模 = 选得准 + 动得对：选择模式、循环选择、相连选择是效率的分水岭。
  2. G / R / S 只是开始：真正让位置精确的是轴约束、数值输入和吸附。
  3. 面一定要朝外：法线错了，后面材质、渲染、导出全是白费。
