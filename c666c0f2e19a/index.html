Blender 建模篇 2.2：十大建模操作

课程：【Kurt】Blender 零基础入门教程（UP 主：KurTips）
章节：建模篇 2.2 · P7 · 时长约 17 分半
上一节：2.1 点线面的选择与控制

一句话总结：这一集是”建模动词表”——把点、线、面变成想要的形状，靠的就是挤出、内插、倒角、环切、挤出流形这五个”造型动作”，再加合并、断开、封面、切刀、桥接这五个”修整动作”。

〇、热身：三个小工具和操控器

正片之前，视频先用几分钟过了几个辅助工具，都很轻量：

工具 位置 用途
标注 Annotate 左侧工具栏的笔 在视图里随手画线写字做标记；按住 Ctrl 涂抹可以擦除
测量 Measure 左侧工具栏 拉一条线量长度、角度；按住 Ctrl 可以吸附到顶点、边
添加模型 Shift + A 快速新建基本体

关于”添加模型”，有一个必须分清的区别：

  • 物体模式下 Shift + A：新建一个独立物体。
  • 编辑模式下 Shift + A：新建的图形会并进当前物体的网格里，它和原来的物体是同一个对象，不是两个。

这个区别后面会反复用到：两个物体不能直接”桥接”，必须先 Ctrl + J 合并；而编辑模式里加出来的东西本来就在同一个物体里。

另外，如果视图里看不到移动用的三个箭头，去视图右上角的操控器（Gizmo）设置里把”移动”勾上即可。

一、挤出 Extrude · E

挤出是建模里出现频率最高的操作，它的本质是给选中的元素”长出”新的几何：

在什么模式 按 E 之后
点模式 新生成一个点，和原来的点连成一条边
边模式 新生成一条边，和原来的边围成一个面
面模式 新生成一个面，和原来的面围成一个体

配合上一节的变换知识：

  • 按下 E 后按 X / Y / Z，可以沿指定轴挤出。
  • 按下 E 后直接输入数字，可以精确控制挤出距离。
  • Ctrl + 右键：在点击的位置快速挤出，一步到位。

1. 新手必踩的坑：右键取消 ≠ 撤销

E 挤出之后，如果点右键，你只是取消了”移动”这一步，挤出的点、线、面仍然留在原地，和原来的面重叠在一起。之后按 G 还能把它拖出来。

这就是很多人”怎么多出来一层””倒角怎么变歪了”的根源。要彻底撤销，请用 Ctrl + Z，而不是右键。

2. Alt + E 里的四个变体

Alt + E 会打开挤出的扩展菜单：

选项 效果 典型用途
沿法向挤出 沿着面的法线方向长出来 给曲面加厚度、做凹凸
挤出各个面 多个面各自独立挤出，可以分别调整 做手指、树枝分叉
挤出至光标 挤出的终点由鼠标点击位置决定 快速定位
挤出流形 智能挤出，自动和相邻面连接（见第五节） 管道、开口、复杂拓扑

二、内插面 Inset · I

内插就是在选中的面内部再缩出一圈面，相当于”向内挤出一个面”。

  • 按 I 后移动鼠标控制内插的宽度，左键确认。
  • 和挤出不同：内插后点右键取消，不会在原地留下一个复制的面。
  • 小技巧：鼠标离物体远一点再按 I，内插的幅度更好控制（鼠标离得近，稍微一动就到底了）。

用途：做面板、窗框、手机屏幕边框；也是倒角前的常用准备动作——先内插出一圈面，再对那圈边倒角，边缘会干净很多。

三、倒角 Bevel · Ctrl + B

倒角是把一条硬邦邦的边”削圆”或”削平”。

  • 选中边 → Ctrl + B → 拖动鼠标控制倒角宽度。
  • 滚动滚轮：增加 / 减少倒角的段数。段数越多越圆滑，1 段就是一条斜切。
  • 按 F9（或点左下角的参数面板）可以随时改：宽度、段数、轮廓。

几个经验：

  • 只选一条边，就是单边倒角；选一圈循环边（Alt + 单击），就是整圈倒角，做圆柱、桌角最常用。
  • 轮廓（Profile）默认 0.5，是标准圆弧；调大或调小会变成外凸 / 内凹的造型。
  • 倒角”变歪””变成扇形”通常不是倒角本身的问题，而是模型里有重叠的点或面（多半是挤出后右键取消留下的）。解决：进点模式 A 全选 → M → 按距离合并，再重新倒角。
  • 视频里的顺序是”先 I 内插，再 Ctrl + B 倒角”，这样得到的是整齐的斜切；直接对边倒角则是圆弧过渡。两种效果没有对错，看你要什么。

四、环切 Loop Cut · Ctrl + R

环切是给模型加一圈线，为后续弯曲、细分、做细节提供支撑。

操作分三步，节奏要记牢：

  1. Ctrl + R，鼠标移到模型上，出现一圈黄色预览线。
  2. 滚动滚轮增加环数（这是唯一的加数量方式）。
  3. 左键落刀 → 移动鼠标滑移位置 → 再左键确认；或者直接右键，让这圈线固定在正中间。

常见问题：

  • 滚轮没反应、变成缩放视图：说明你是点了左侧工具栏的环切图标，而不是用快捷键 Ctrl + R 进入了环切模式。必须用快捷键，且进入后不要先点空白处。
  • 环切在四边形网格上才顺畅；遇到三角面、n-gon 会中断。
  • 环切出来的线默认是”滑移”状态，没确认前都可以左右挪，确认后就固定了。

五、挤出流形 Extrude Manifold · Alt + E

普通挤出（挤出选区）是”复制一份再移动”，会在原位置留下重复的边和面；挤出流形是”生长并连接”，会智能处理和相邻面的关系，保持网格干净。

挤出选区（E） 挤出流形（Alt + E）
逻辑 复制并移动 生长并连接
重复几何 容易留下内部重复面 自动处理，保持水密
适用 简单的凸起、加厚 管道、分支、开口、复杂拓扑

注意两点：

  1. 新版 Blender 里，”挤出流形”藏在长按挤出图标弹出的小菜单里，或者用 Alt + E 选择。
  2. 如果按 Alt + E 之后发现多出一圈”薄片”，通常是因为误按过一次 E（哪怕你右键取消了），留下了薄边。先 Ctrl + Z 撤干净，再重新操作。

六、合并 Merge · M

M 是把选中的点”焊”到一起，菜单里有几种方式：

方式 说明
到中心 所有选中点合并到它们的几何中心
到光标 合并到 3D 游标的位置
首选点 / 末选点 合并到第一个 / 最后一个选中的点
按距离 距离小于阈值的点自动合并，最常用
  • “首选点 / 末选点”需要按住 Shift 依次点选两个点才有顺序；框选、刷选是分不出先后的。
  • 按距离合并是清理模型的神器：挤出取消留下的重叠点、导入模型带进来的垃圾顶点，全选后 M → 按距离，一次清干净。阈值在左下角面板里调，别调太大，否则会把该保留的细节也焊掉。

七、断开 Rip · V

V 是”撕开”：把一个顶点连同它连接的边拆开，让原本连着的面可以分开。

  • 顶点必须连着三个以上的面，按 V 才能撕开（只连两个面的话，撕开没有意义）。
  • 撕开之后按 G，就能像”开盖”一样把一部分掀起来。
  • 如果按 V 只开了一个面，多半是选择范围不对：把相邻的点一起选上，或者检查拓扑是不是本来就没连上。

用途：做盒子的开口、翻盖、眼睑、嘴部、书页。

八、封面：F 与栅格填充

模型上有洞的时候，需要把洞补上，有两种做法：

1. 快速封面 F

选中一圈循环边，按 F，直接填一个 n-gon（多边形面）。快，但 n-gon 在细分、渲染时可能出问题。

2. 栅格填充 Grid Fill

选中一圈循环边 → 面菜单（Ctrl + F）→ 栅格填充，会填成整齐的四边面网格，还能在左下角调跨度、偏移。

  • 必须是偶数条边才能栅格填充。
  • 奇数条边怎么办：选中其中一条边 → 右键 → 细分，把它变成两条，凑成偶数，再填充。
  • 视频里老师口误说成了 Ctrl + E，Ctrl + E 是边菜单，Ctrl + F 才是面菜单。

九、切刀 Knife · K

切刀是”手动加线”的工具，鼠标点到哪里，就在哪里切一刀。

操作 效果
K 进入切刀工具
左键点击 落一个切点，连续点击就连成切线
空格 / 回车 确认切割并退出工具
右键 结束当前这条切线，但仍留在切刀工具里
Esc 放弃这次切割（已经画的线会消失）
C 切换”穿透切割”，一刀切透整个物体；再按一次恢复只切可见面

用途：在平面上切出 logo 轮廓、给 n-gon 补线、做不规则的分割。切完记得确认，别习惯性按 Esc 把刚画好的线全丢了。

不同版本对右键、空格的响应略有差异，拿不准就看左下角状态栏的提示。

十、桥接 Bridge · Ctrl + E

桥接是把两圈边数相同的循环边用面连起来，做管道、手臂、脖子、袖口特别方便。

  1. 选中两圈循环边（Alt + 单击 各选一圈）。
  2. Ctrl + E → 桥接循环边。
  3. 在左下角调段数、偏移、平滑。

两个前提：

  • 两个物体不能直接桥接。要先把它们 Ctrl + J 合并成一个物体，再进编辑模式桥接。
  • 两圈边的边数必须相同，否则会报错或扭成一团。边数不够的一边，先用环切 Ctrl + R 加线。

收尾两件套：合并物体 Ctrl + J 与分离 P

这两个是物体级别的操作，和上面的”合并点 M“不是一回事：

操作 快捷键 作用
合并物体 Join Ctrl + J 把多个物体合并成一个（材质保留，原点取活动物体）
分离 Separate P 把选中的部分拆成独立物体，可选”选中项 / 按材质 / 按松散块”
  • 分离出来的部分原点还在原处，旋转、缩放时会觉得”绕得很远”，这是正常的。
  • 分离后如果动一个部分、其他部分跟着动，先检查顶部的衰减编辑（那个小圆点，快捷键 O）是不是开着，关掉即可。

快捷键速查

操作 快捷键 一句话
挤出 E 点长线、线长面、面长体
快速挤出 Ctrl + 右键 点到哪长到哪
挤出菜单 Alt + E 沿法向 / 各个面 / 至光标 / 流形
内插面 I 面内再缩一圈
倒角 Ctrl + B 滚轮加段数
环切 Ctrl + R 滚轮加环数，左键落刀
合并点 M 按距离合并最常用
断开 V 撕开顶点，开盖
封面 F 填一个 n-gon
栅格填充 Ctrl + F 填四边面网格，需偶数边
切刀 K 空格确认，C 穿透
桥接 Ctrl + E 两圈等边数的边
合并物体 Ctrl + J 多个物体并成一个
分离 P 拆成独立物体
参数面板 F9 改上一步操作的数值

踩坑清单

  1. 挤出后右键取消，模型多了一层：右键只取消了移动，几何还在。要彻底撤销用 Ctrl + Z。
  2. 滚轮不能加环数 / 加倒角段数：必须用快捷键进入操作，不能点工具栏图标；也不要在操作中先点空白处确认。
  3. 倒角变歪、变扇形：多半有重叠点。点模式 A 全选 → M 按距离合并 → 重新倒角。
  4. 环切切不动：检查是不是四边形区域；三角面、n-gon 会中断环切。
  5. 栅格填充没反应：边数是奇数。先细分一条边凑成偶数。
  6. 桥接报错：两个物体没合并（先 Ctrl + J），或者两圈边数不一样。
  7. 切刀切完线没了：按了 Esc。Esc 是放弃，确认要用空格或回车。
  8. 分离后一动全动：关掉衰减编辑（O），或检查轴心点。
  9. 按 Alt + Z 弹出显卡面板：驱动热键冲突，去驱动里改掉。

练习：把十个动作串起来

  1. 新建立方体 → I 内插顶面 → E 向上挤出 → Ctrl + B 给四条竖边倒角 → Ctrl + R 加两圈线，做一个带圆角的”音箱”。
  2. 新建两个圆柱，物体模式 Ctrl + J 合并 → 编辑模式各选一圈边 → Ctrl + E 桥接，做一根弯管。
  3. 用 K 切刀在一个面上切出简单的字母轮廓，再 E 挤出，做立体字。
  4. 立方体选顶面 I 内插 → 删掉中间的面 → 选一圈边 V 断开、G 掀起，做一个开盖的盒子。
  5. 用 Alt + E → 挤出流形做一条分支管道，对比普通 E 挤出留下的内部面。

复盘

  • 造型五件套：挤出（长）、内插（缩）、倒角（圆）、环切（加线）、挤出流形（干净地长）。
  • 修整五件套：合并（焊点）、断开（撕开）、封面（补洞）、切刀（加刀）、桥接（连边）。
  • 两条铁律：右键取消不等于撤销；两个物体要先合并才能桥接。
